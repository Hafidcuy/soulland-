# Modpack: Soul Land: Douluo Dalu

Paket ini berisi mod inti `soulland` (kultivasi Benua Douluo) plus mod pendukung
yang_role-nya saling melengkapi. Semua versi diambil dari Modrinth saat
`tools/build_modpack.py` dijalankan, jadi angkanya selalu terverifikasi.

| Mod | Peran | Versi | Kenapa ada |
|---|---|---|---|
| Curios API | Slot aksesori | 5.14.1+1.20.1 | Sembilan spirit ring adalah aksesori, bukan isi tas. Curios memberi slot ring khusus sehingga cincin tidak memenuhi tas, dan menyisakan ruang untuk bahan halus. |
| Jade 🔍 | HUD, minimap, dan info pemain | 11.13.3+forge | HUD kultivasi mod inti sudah occupies kiri atas, jadi Jade dipasang hanya untuk minimap dan informasi target. Minimap penting untuk berburu soul beast yang-tier-nya jelas. |
| Waystones | Teleportasi antar wilayah | 14.1.21+forge-1.20.1 | Perburuan soul beast jadi soal perjalanan, bukan jarak berjalan. Waystones memberi jaringan warp yang bisa dibatasi per wilayah. |
| Moonlight Lib | Bioma dan worldgen | 1.20-2.16.37-forge | Variasi permukaan untuk Benua Douluo: bukit, rawa, dan hutan yang berbeda dari vanilla, supaya berburu terasa seperti menjelajah wilayah. |
| Supplementaries | Dekorasi dan furnitur | 1.20-3.1.44-forge | Bangunan klan, tenda, altar, dan perapian ritual butuh blok dekoratif. Supplementaries tidak menambah progression, jadi aman digabung. |
| Apotheosis | Affix dan rune | 7.4.8 | Spirit ring bisa punya afiks dan rune. Ini yang membuat cincin terasa sebagai barang yang diburu, bukan sekadar angka. |
| Architectury API | Library | 9.2.14+forge | Beberapa mod di pack ini menarik API-nya lewat Architectury. Satu versi Forge 1.20.1 saja yang dipasang supaya tidak bentrok. |
